# مجمداتكو — B2B Frozen Food Distribution App (Prototype)

منصة توريد وتوزيع مجمدات لأصحاب المحلات — من مؤسسة المزرعاوي للمجمدات.

هذا مستودع يحتوي **بروتوتايب تفاعلي كامل** (Front-end فقط، بدون Backend) لتجربة الاستخدام
والتصميم، مبني بـ HTML/CSS/JavaScript فقط بدون أي أطر عمل أو خطوة بناء (build step) —
يفتح ويشتغل مباشرة من أي متصفح.

## 🚀 تشغيل المشروع محليًا

ما في حاجة لتنصيب أي شيء. فقط افتح الملف مباشرة:

```bash
git clone <رابط-المستودع>
cd mujammadatco-app
open index.html   # أو اسحبه لأي متصفح
```

أو شغّل سيرفر محلي بسيط (اختياري، لتفادي بعض قيود المتصفح مع الخطوط):

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## 🧩 ما هو مبني داخل index.html

- كل الواجهة (Header, الأقسام, العروض, صفحة القسم, صفحة المنتج) في صفحة واحدة self-contained.
- بيانات المنتجات، الأقسام، والطلبات موجودة كمصفوفات JavaScript داخل الملف (`CATS`, `PRODUCTS`,
  `OFFERS`, `ORDERS`) — تقدر تعدّلها أو تربطها لاحقًا بـ API حقيقي.
- التنقل بين الشاشات (الرئيسية ← القسم ← المنتج ← طلبك ← مراجعة الطلب ← تأكيد) مبني كـ SPA خفيف
  بدون أي مكتبة توجيه (router)، فقط JS عادي.
- الخطوط: Almarai و IBM Plex Sans Arabic عبر Google Fonts CDN.
- لا يوجد تخزين متصفح دائم (localStorage) — حالة السلة/الطلب تُحفظ في الذاكرة فقط وتُصفّر عند
  إعادة تحميل الصفحة، لأن هذا لسا Prototype وليس نسخة إنتاج متصلة بقاعدة بيانات.

## ⚠️ ملاحظات قبل أي استخدام تجاري فعلي

- شعارات الشركات الموزَّعة (نبيل، سنيورة، الوادي، أمريكانا...) المستخدمة داخل التطبيق هي علامات
  تجارية مملوكة لأصحابها، واستخدامها هنا لغرض تعريف المنتجات الموزَّعة فقط — تأكد من توثيق اتفاقية
  التوزيع/الإذن باستخدامها قبل النشر العام أو التسويق الرسمي.
- هذا Prototype تصميمي وتجربة استخدام (UX/UI) فقط: لا يوجد Backend حقيقي، لا مصادقة مستخدمين،
  ولا اتصال بقاعدة بيانات أو نظام مخزون فعلي. الخطوة التالية الطبيعية هي بناء API (REST/GraphQL) +
  قاعدة بيانات، وربط الشاشات الحالية فيه.

## 📢 لوحة الإعلانات (اختياري — يحتاج ربط خارجي)

التطبيق فيه لوحة إعلانية على الشاشة الرئيسية، وزر "إضافة صورة للوحة الإعلانية" داخل **لوحة
التحكم الداخلية** (اضغط شعار مجمداتكو 3 مرات، كلمة المرور: `199611`). هذه الميزة تحتاج ربط
حسابين مجانيين حتى تشتغل فعليًا (بدونهم البروتوتايب يشتغل عادي، بس اللوحة تظل فاضية):

1. **Firebase** — لتخزين قائمة روابط الصور (وليس الصور نفسها، حتى ما يكبر حجم التطبيق):
   - أنشئ مشروع مجاني على https://console.firebase.google.com
   - فعّل **Firestore Database** (ابدأ بوضع Test mode)
   - من *Project settings → General → Your apps* أضف تطبيق ويب وانسخ بيانات `firebaseConfig`
2. **imgbb** — لاستضافة الصورة نفسها ورفعها:
   - أنشئ حساب مجاني على https://api.imgbb.com/
   - خذ الـ API Key من لوحة حسابك

بعدين افتح `index.html` ولاقي القسم بالأعلى المكتوب فيه "⚙️ إعدادات الربط الخارجي" وحط
قيمك مكان الحقول اللي كاتبة "ضع ... هنا". هيك بس، بدون ما تلمس أي كود تاني.

> ⚠️ هذا الربط **ما رح يشتغل داخل معاينة Claude نفسها** لأنها بيئة معزولة أمنيًا ما بتسمح
> باتصالات خارجية أو تحميل صور من الإنترنت. لازم تفتح الملف من استضافة حقيقية (GitHub Pages
> أو أي سيرفر) حتى يشتغل الرفع والعرض الفعلي.

## ✨ لوحة التحكم الجديدة
تم تحديث النموذج ليشمل لوحة تحكم متجاوبة بأسلوب مركز عمليات المتجر، ويمكن فتحها من التطبيق عبر الضغط 3 مرات على شعار مجمداتكو ثم إدخال كلمة المرور الحالية `199611`.

تشمل اللوحة:
- نظرة عامة على المبيعات والطلبات والمنتجات ومتوسط قيمة الطلب.
- إدارة المنتجات: إضافة، تعديل، حذف، السعر، الوحدة، الشركة والقسم.
- إدارة الأقسام مع عدد المنتجات والحالة.
- إدارة الطلبات وتحديث حالتها من قيد التجهيز إلى التوصيل أو الاكتمال.
- إدارة الإعلانات والبنرات.
- إعدادات المتجر الأساسية ومعاينة المتجر.
- إزالة شريط الساعة التجريبي `9:41` من جميع الشاشات.

> ملاحظة: التخزين الحالي داخل النموذج تجريبي في الذاكرة. لتشغيل الإدارة بشكل دائم بين الأجهزة، اربطها بقاعدة بيانات وواجهة API، ثم فعّل Firebase/Backend في مرحلة الإنتاج.
